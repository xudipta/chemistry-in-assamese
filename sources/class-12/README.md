# Source PDFs (reference only)

Upload the Class 12 chemistry textbook PDFs here, e.g.

- `chemistry-assamese.pdf`
- `chemistry-english.pdf`

These are used only to confirm the chapter list and Assamese terminology. They are **not** part of the website
(the deploy workflow publishes only `index.html`, `chapter.html`, `assets/`, `content/` and the service worker),
and this branch should be deleted once the content is written. Files over 25 MB can't be added through the
GitHub web upload: split the PDF into parts first.
